# Консольное приложение: арифметический калькулятор и конвертер физических величин

Лабораторная работа №1: консольное приложение на Python, содержащее калькулятор арифметических
выражений и конвертер физических величин.

## Возможности

### Калькулятор (calc):

- Поддерживаются целые и вещественные числа
- Поддерживаются операции `+`, `-`, `*`, `/`, `//`, `%`
- Поддерживаются скобки `(`, `)`
- Поддерживаются унарные `+` и `-` перед числом (но не перед скобками)
- Игнорируются пробелы между токенами
- Учитывается приоритет операций и скобок
- Запрещён формат ввода вещественных чисел без дробной части `2131.`
- Целые результаты выводятся без `.0`

Выражение разбивается на токены, проходит проверку синтаксиса,
преобразуется в обратную польскую нотацию (RPN) и вычисляется
с использованием стека.

### Конвертер (convert)

Поддерживаемые группы:

- длина: `mm`, `cm`, `m`, `km`
- масса: `g`, `kg`
- температура: `c`, `f`, `k`

Правила:

- регистр единиц не учитывается
- конвертация между разными группами запрещена
- температура ниже абсолютного нуля запрещена
- значения массы и длины ниже нуля запрещены
- результат возвращается как `float`

Конвертация состоит из валидации введённых аргументов и перевода значения
из одной величины в другую путём промежуточного преобразования в базовую единицу (`m`, `kg`, `c`)

## Поддерживаемые команды

```shell
python -m toolkit calc "EXPRESSION"

python -m toolkit convert VALUE --from UNIT --to UNIT

python -m toolkit --help

python -m toolkit calc --help

python -m toolkit convert --help
```

## Примеры использования

```shell
python -m toolkit calc "2 + 3 * 4"
# 14

python -m toolkit calc "-3 * (4 / (10 - 2))"
# 1.5

python -m toolkit convert 1.5 --from kg --to g
# 1500.0

python -m toolkit convert 0 --from c --to f
# 32.0
```

## Обработка ошибок

- **Калькулятор**: пустое выражение, недопустимый символ, пропущенный операнд/оператор,
  деление на ноль, несбалансированные скобки, числа вида `123.` без цифр после точки
- **Конвертер**: неизвестная единица, несовместимые единицы,
  температура ниже абсолютного нуля, отрицательные значения длины и массы

Коды возврата: `0` - успех, `2` - ошибка вычисления или
конвертации (CLI выводит ошибку в `stderr`)

## Команды проверки

### Тесты

Автоматические тесты написаны на `pytest` и покрывают как успешные сценарии, так и ошибки.
Имеются тесты калькуляторы, конвертера и CLI (всего 30 штук).

Для запуска всех тестов:

```shell
python -m pytest
```
